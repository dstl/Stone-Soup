Demonstrations
==============

Here are a selection of demonstrations of Stone Soup against real data sets.

Running downloaded demonstrations
---------------------------------

Sphinx-Gallery downloads do not necessarily include supporting data files,
assets, optional packages, or resources fetched from the network. Before
running a downloaded demonstration, read its full documentation page for the
setup instructions and links to any additional resources it requires.

For restricted or isolated environments, obtain those resources before moving
the demonstration into the restricted environment. A repository checkout is
the simplest option when the demonstration relies on files stored alongside
its source.
